# Архитектурное ревью MemeGenerator

Проверено состояние `main` от 22.10.2026 (commit `85133b5`):
доменные модели, application и protocols, composition, конфигурация, CLI,
поставщики изображений и LLM, FFmpeg, файловые и SQL-каталоги,
импорт медиа, тесты и import-linter.

## Что уже организовано правильно

- Домен не импортирует адаптеры, application опирается на явные
  `*Protocol`, составление зависимостей вынесено в `composition`.
- SQLite/PostgreSQL проверяются на реальных транзакциях, а не моках ORM.
- LLM-план валидируется по каталогу и количеству сцен до монтажа;
  постоянные ошибки структурированного ответа не повторяются через retry.
- Видео и JSON-манифесты сначала готовятся во временном каталоге,
  затем публикуются с резервными копиями для отката при ошибке файловой операции.

## Ограничения текущего PR

Вынесен общий низкоуровневый осмотр медиа, но **не объединены** правила
импорта (`audio` обязателен, продолжительность ограничена) и монтажа
(аудио может отсутствовать). Дублирующихся классов или глобального
сервис-локатора не добавлено. Публичные функции `probe_clip`,
`probe_media` и `verify_normalized` сохраняются.
